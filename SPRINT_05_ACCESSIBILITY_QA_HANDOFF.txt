18. CONFIRMED DEFECT 1 - SCROLLABLE REGIONS NOT KEYBOARD-FOCUSABLE
--------------------------------------------------------------------------------
[VERIFIED] The horizontally scrollable pipeline (#pipelineFlow) and delivery board
(#kanbanBoard) were scrollable but not keyboard-focusable (axe scrollable-region-
focusable), so keyboard-only users could not scroll them. Repair: added tabindex="0"
and a role="group" with a descriptive aria-label to each, making them focusable and
giving the group an accessible name without altering layout or visuals.

--------------------------------------------------------------------------------
19. CONFIRMED DEFECT 2 - DECORATIVE NAV ICONS POLLUTE LINK NAMES
--------------------------------------------------------------------------------
[VERIFIED] Each side-navigation link prefixed its text with a decorative glyph in a
bare <span>, so the glyph leaked into the link's accessible name. Repair: marked the
13 decorative glyph spans aria-hidden="true" so assistive technology announces only
the human-readable link text. No visual change.

--------------------------------------------------------------------------------
20. CONFIRMED DEFECT 3 - ERROR PATH INJECTS A PARAGRAPH INTO A LIST
--------------------------------------------------------------------------------
[VERIFIED] The fatal-error renderer (showFatal in hub.js) appended a <p> into every
host, including <ol>/<ul> hosts, producing invalid list structure (axe list rule)
when the app failed closed. Repair: showFatal now detects a list host (tagName OL/UL)
and appends a list item there and a paragraph elsewhere, so the honest error message
is emitted with valid structure in every host.

--------------------------------------------------------------------------------
