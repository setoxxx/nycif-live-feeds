       'nycif-app/god-view/hub/release-audit.json']
    Cause: the check used `git diff --name-only`, which lists ONLY tracked
    file modifications. Those 3 required outputs were newly UNTRACKED files, so
    they were invisible to the check and the "required outputs were produced"
    assertion failed. (The 3 already-tracked outputs did show up.)
    Every other step passed in all runs; the failure was isolated to this step.

        git diff --name-only
    with:

          | sort -u
    This ADDS untracked files to the set. Effects:
      - "No unexpected writes" assertion becomes STRICTER (untracked stray
        files would now also be caught).
      - "Required outputs produced" assertion now correctly sees newly created
        files.

    logs.
